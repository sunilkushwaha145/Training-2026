HTML Concepts

HTML Structure

HTML documents follow a nested structure where the <html> tag contains the <head> and <body>.

Tag – Attribute – Value

A tag is the element, an attribute provides properties and the value defines that property.
Format: <tag attribute="value">
Examples:
1. <html lang="en">
2. <meta charset="UTF-8">
3. <a href="index.html">
4. <img src="pic.jpg">
5. <link rel="icon">

Head Tag Concepts

<title>: Defines page title for browser tab.
<link rel="icon">: Adds a favicon image.

Paragraph Tag

The <p> tag defines a block of text.
