IF Statement

Syntax:
if (condition) {
  // code to execute if condition is true
}

The IF statement executes code only if a specified condition is true. If the condition is false, the code inside the if block is skipped.

Example 1: Simple Number Check
Problem: Check if a number is positive
let num = 10;
if (num > 0) {
console.log("The number is positive");
}
Output: The number is positive
Example 2: Age Check
Problem: Check if age is adult (18+)
let age = 20;
if (age >= 18) {
console.log("You are an adult");
}
Output: You are an adult
Example 3: String Comparison
Problem: Check if password is correct
let password = "secret123";
if (password === "secret123") {
console.log("Password is correct");
}
Output: Password is correct
Example 4: Multiple Conditions with AND
Problem: Check if user can drive (age >= 18 AND has license)
let age = 25;
let hasLicense = true;
if (age >= 18 && hasLicense === true) {
console.log("You can drive");
}
Output: You can drive
Example 5: Empty Array Check
Problem: Check if array is not empty
let arr = [1, 2, 3];
if (arr.length > 0) {
console.log("Array has elements");
}
Output: Array has elements
Example 6: Even Number Check
Problem: Check if number is even
let num = 24;
if (num % 2 === 0) {
console.log("Number is even");
}
Output: Number is even
Example 7: Price Range Check
Problem: Check if price is within budget
let price = 500;
let budget = 1000;
if (price <= budget) {
console.log("Item is affordable");
}
Output: Item is affordable
Example 8: Multiple OR Conditions
Problem: Check if user is admin or moderator
let role = "admin";
if (role === "admin" || role === "moderator") {
console.log("You have special privileges");
}
Output: You have special privileges
Example 9: NOT Operator Check
Problem: Check if container is not empty
let isEmpty = false;
if (!isEmpty) {
console.log("Container has items");
}
Output: Container has items
Example 10: Range Check
Problem: Check if score is in passing range (40-100)
let score = 75;
if (score >= 40 && score <= 100) {
console.log("Score is valid and passing");
}
Output: Score is valid and passing

IF-ELSE Statement

Syntax:
if (condition) {
  // code if condition is true
} else {
  // code if condition is false
}

The IF-ELSE statement executes one block of code if the condition is true and another block if it's false. This provides two alternative paths of execution.

Example 1: Pass/Fail Check
Problem: Determine if student passed (score >= 40)
let score = 35;
if (score >= 40) {
console.log("PASS");
} else {
console.log("FAIL");
}
Output: FAIL
Example 2: Even or Odd
Problem: Check if number is even or odd
let num = 7;
if (num % 2 === 0) {
console.log("Even number");
} else {
console.log("Odd number");
}
Output: Odd number
Example 3: Age Category
Problem: Determine if person is adult or minor

Example 4: Login Verification

Example 5: Voting Eligibility

NESTED IF

Syntax:
if (condition1) {
  if (condition2) {
    // code
  }
}

Nested IF statements are IF statements inside another IF statement. This allows for more complex decision-making with multiple levels of conditions.

Example 1: Voting and License Check
Problem: Check if person can vote (age >= 18) AND is a citizen (true)
let age = 25;
let isCitizen = true;
if (age >= 18) {
if (isCitizen) {
console.log("You can vote");
}
}
Output: You can vote
Example 2: Bank Withdrawal
Problem: Can withdraw if account exists AND balance is sufficient
let accountExists = true;
let balance = 5000;
let withdrawal = 2000;
if (accountExists) {
if (balance >= withdrawal) {
console.log("Withdrawal approved");
}
}
Output: Withdrawal approved
Example 3: Employee Bonus Eligibility
Problem: Bonus if employee worked > 1 year AND performance is good
let yearsWorked = 3;
let performanceRating = "good";
if (yearsWorked > 1) {
if (performanceRating === "good") {
console.log("Eligible for bonus");
}
}
Output: Eligible for bonus
Example 4: Scholarship Eligibility
Problem: Scholarship if marks >= 80 AND family income is low
let marks = 85;
let familyIncome = "low";
if (marks >= 80) {
if (familyIncome === "low") {
console.log("Scholarship awarded");
}
}
Output: Scholarship awarded
Example 5: Access Control
Problem: Access granted if logged in AND role is admin
let isLoggedIn = true;
let role = "admin";
if (isLoggedIn) {
if (role === "admin") {
console.log("Access granted to admin panel");
}
}
Output: Access granted to admin panel

LADDER IF (If-Else-If)

Syntax:
if (condition1) {
  // code
} else if (condition2) {
  // code
} else if (condition3) {
  // code
} else {
  // code
}

Ladder IF (If-Else-If) allows checking multiple conditions in sequence. The first true condition executes and the rest are skipped. This is perfect for multiple mutually exclusive choices.

Example 1: Grade Assignment
Problem: Assign grade based on marks
let marks = 75;
if (marks >= 90) {
console.log("Grade: A");
} else if (marks >= 80) {
console.log("Grade: B");
} else if (marks >= 70) {
console.log("Grade: C");
} else if (marks >= 60) {
console.log("Grade: D");
} else {
console.log("Grade: F");
}
Output: Grade: C
Example 2: Age Category
Problem: Categorize person by age group
let age = 35;
if (age < 13) {
console.log("Child");
} else if (age < 18) {
console.log("Teenager");
} else if (age < 60) {
console.log("Adult");
} else {
console.log("Senior");
}
Output: Adult
Example 3: Traffic Light System
Problem: Display action based on traffic light
let light = "yellow";
if (light === "red") {
console.log("STOP");
} else if (light === "yellow") {
console.log("WAIT");
} else if (light === "green") {
console.log("GO");
}
Output: WAIT
Example 4: Salary Range Classification
Problem: Classify salary into brackets
let salary = 50000;
if (salary < 25000) {
console.log("Low salary");
} else if (salary < 50000) {
console.log("Medium salary");
} else if (salary < 100000) {
console.log("High salary");
} else {
console.log("Very high salary");
}
Output: High salary
Example 5: Ticket Price by Age
Problem: Determine ticket price based on age
let age = 8;
if (age < 5) {
console.log("Ticket: Free");
} else if (age < 12) {
console.log("Ticket: $5 (Child)");
} else if (age < 60) {
console.log("Ticket: $10 (Adult)");
} else {
console.log("Ticket: $7 (Senior)");
}
Output: Ticket: $5 (Child)
