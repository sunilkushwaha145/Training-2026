Arithmetic Operators

Arithmetic operators perform mathematical calculations on numeric values. They include addition, subtraction, multiplication, division and modulus (remainder).

Addition (+)

Example 1
let a = 10;
let b = 5;
let sum = a + b;
console.log(sum); // 15
Output: 15
Simple addition: 10 + 5 = 15
Example 2
let x = 2.5;
let y = 3.7;
console.log(x + y); // 6.2
Output: 6.2
Addition works with decimals: 2.5 + 3.7 = 6.2
Example 3
let text1 = "Hello";
let text2 = " World";
console.log(text1 + text2); // Hello World
Output: Hello World
Addition also concatenates strings: "Hello" + " World" = "Hello World"
Example 4
console.log(5 + 3 + 2); // 10
console.log(1 + 2 + 3 + 4 + 5); // 15
Output: 10
Output: 15
Multiple additions are evaluated left to right: 5 + 3 + 2 = (5+3) + 2 = 10
Example 5
let quantity = 3;
let price = 50.99;
let total = quantity + price;
console.log("Total: Rs" + total); // Total: $153.97
Output: Total: Rs 153.97
Addition in real-world scenarios like calculating totals

Relational (Comparison) Operators

Relational operators compare values and return boolean results (true or false). They're essential for decision-making.

Operator Name Example Result
> Greater than 5 > 3 true
< Less than 5 < 3 false
>= Greater than or equal 5 >= 5 true
<= Less than or equal 5 <= 5 true
== Equal (loose) 5 == "5" true
=== Strict equal 5 === "5" false
!= Not equal (loose) 5 != 3 true
!== Strict not equal 5 !== "5" true

Equality: == vs ===

== (Loose Equality): Compares values, performing type conversion if needed. "5" == 5 is true.

=== (Strict Equality): Compares both value AND type. No conversion. "5" === 5 is false.

Best Practice: Always use === and !== in modern JavaScript to avoid unexpected behavior.

Example 6: == (Loose Equality)
console.log(5 == "5"); // true (values equal, types differ)
console.log(5 == 5); // true (values and types equal)
console.log(0 == false); // true (0 converts to false)
console.log("" == false); // true (empty string converts to false)
console.log(null == undefined); // true (special case)
Output: true
Output: true
Output: true
Output: true
Output: true
Loose equality performs type coercion. JavaScript converts types to compare values. 5 and "5" are equal because JavaScript converts "5" to number 5 before comparing.
Example 7: === (Strict Equality)
console.log(5 === "5"); // false (different types)
console.log(5 === 5); // true (same value and type)
console.log(0 === false); // false (different types)
console.log("" === false); // false (different types)
console.log(null === undefined); // false
Output: false
Output: true
Output: false
Output: false
Output: false
Strict equality checks both value AND type. 5 and "5" are NOT equal because one is a number and the other is a string. No type conversion happens.
Example 8: More Comparisons
console.log("hello" == "hello"); // true
console.log("hello" === "hello"); // true
console.log("10" == 10); // true (loose)
console.log("10" === 10); // false (strict)
console.log(true == 1); // true (loose)
console.log(true === 1); // false (strict)

Output: true
Output: true

Output: true
Output: false

Logical Operators

Logical operators combine boolean values and return boolean results. They're used for complex conditional logic.

AND (&&) - All conditions must be true

Example 1
console.log(true && true); // true
console.log(true && false); // false
console.log(false && false); // false
Output: true
Output: false
Output: false
AND returns true only when BOTH values are true
Example 2
let age = 25;
let hasLicense = true;
console.log(age > 18 && hasLicense); // true
Output: true
Both conditions are true, so the result is true
Example 3
let score = 50;
let passed = score >= 40;
let qualified = score >= 60;
console.log(passed && qualified); // false
Output: false
First condition is true but second is false. AND returns false

OR (||) - At least one condition must be true

Example 4
console.log(true || true); // true
console.log(true || false); // true
console.log(false || false); // false
Output: true
Output: true
Output: false
OR returns true if AT LEAST ONE value is true
Example 5
let isStudent = false;
let isTeacher = true;
console.log(isStudent || isTeacher); // true
Output: true
One condition is true, so OR returns true
Example 6
let hasPassport = false;
let hasVisa = false;
console.log(hasPassport || hasVisa); // false
Output: false
Both conditions are false, so OR returns false

NOT (!) - Inverts/Negates boolean value

Example 7
console.log(!true); // false
console.log(!false); // true
console.log(!!true); // true (double negation)
Output: false
Output: true
Output: true
NOT inverts the boolean value. Double NOT returns original
Example 8
let isEmpty = true;
console.log(!isEmpty); // false
if (!isEmpty) {
console.log("Container is not empty");
} else {
console.log("Container is empty");
}
Output: false
Output: Container is empty
NOT is useful in conditional statements to check opposite conditions
Example 9
let hasAdmin = false;
let hasUser = true;
console.log(!hasAdmin && hasUser); // true
console.log(!hasAdmin || !hasUser); // true
Output: true
Output: true
NOT can be combined with AND/OR for complex logic
Example 10
let canApply = (age >= 18) && (noOutstandingDebt) && (!isBlacklisted);
let canVote = (age >= 18) && (isCitizen);
let needsReview = !approvedByManager || flaggedForAudit;
Complex logical expressions combining AND, OR and NOT for real-world scenarios

c *= 3 multiplies c by 3 and assigns the result back

Increment and Decrement Operators

These operators increase or decrease a value by 1. The position matters: prefix (++a) vs postfix (a++)

Understanding ++a (Pre-increment) vs a++ (Post-increment)

Example 1: ++a (Pre-increment)
let x = 5;
let result = ++x; // Increment FIRST, then return
console.log("x: " + x); // x: 6
console.log("result: " + result); // result: 6
Output: x: 6
Output: result: 6
++x increments x to 6, THEN returns 6 to result. Both x and result are 6. Step 1: x becomes 6
Step 2: Return 6 to result
Example 2: a++ (Post-increment)
let y = 5;
let result = y++; // Return FIRST, then increment
console.log("y: " + y); // y: 6
console.log("result: " + result); // result: 5
Output: y: 6
Output: result: 5
y++ returns the original value 5 to result, THEN increments y to 6. Step 1: Return 5 to result
Step 2: y becomes 6
Example 3: ++a in Loop
for (let i = 1; i <= 3; i++) {
console.log(i);
}
// Output: 1, 2, 3
// Step-by-step: i=1 (print), i++→i=2 (print), i++→i=3 (print), i++→i=4 (loop ends)
Output: 1
Output: 2
Output: 3
In loops, i++ is typically used because the return value isn't needed. Loop increments: 1→2→3→4(exit)
Example 4: Decrement --a
let count = 10;
--count; // Pre-decrement
console.log(count); // 9

let num = 10;
let result = num--; // Post-decrement
console.log("num: " + num); // num: 9
console.log("result: " + result); // result: 10
Output: 9
Output: num: 9
Output: result: 10
Decrement works similarly to increment. --num reduces first, num-- reduces after.
Example 5: Countdown
let countdown = 5;
console.log(countdown--); // 5
console.log(countdown--); // 4
console.log(countdown--); // 3
console.log(countdown--); // 2
console.log(countdown--); // 1
console.log(countdown--); // 0
Output: 5
Output: 4
Output: 3
Output: 2
Output: 1
Output: 0
Each countdown-- prints current value, then decrements. 5→4→3→2→1→0
Example 6: Complex Expression
let a = 5;
let b = 10;
let result = ++a + b++;
// ++a: a becomes 6, returns 6
// b++: returns 10, then b becomes 11
// result = 6 + 10 = 16
console.log("a: " + a); // a: 6
console.log("b: " + b); // b: 11
console.log("result: " + result); // result: 16
Output: a: 6
Output: b: 11
Output: result: 16
Mixing pre and post increments: ++a returns 6 (a becomes 6)
b++ returns 10 (b becomes 11)
6 + 10 = 16
Example 7: Array Index Increment
let arr = ["a", "b", "c"];
let index = 0;
console.log(arr[index++]); // "a" (then index becomes 1)
console.log(arr[index++]); // "b" (then index becomes 2)
console.log(arr[index++]); // "c" (then index becomes 3)
console.log("Final index: " + index); // Final index: 3
Output: a
Output: b
Output: c
Output: Final index: 3
Post-increment is common with array access because you use current index, then move to next.
Example 8: Practical Counter
let counter = 0;
counter++; // counter: 1
counter++; // counter: 2
counter++; // counter: 3
console.log("Count: " + counter); // Count: 3

// Reset and decrement
counter = 3;
counter--; // counter: 2
counter--; // counter: 1
console.log("New Count: " + counter); // New Count: 1
Output: Count: 3
Output: New Count: 1
Common pattern: incrementing/decrementing counters for tracking.
Example 9: Score Tracking
let playerScore = 0;
// Player scores 10 points
playerScore += 10; // playerScore: 10
// Bonus point
++playerScore; // playerScore: 11
console.log("Score: " + playerScore); // Score: 11

// Penalty
playerScore--;
console.log("Final Score: " + playerScore); // Final Score: 10
Output: Score: 11
Output: Final Score: 10
Real-world use: tracking game scores with increments and decrements.
Example 10: Loop Counter
let n = 0;
while (n < 3) {
console.log("Iteration: " + ++n);
}
// Using ++n ensures n is incremented before being used
// n=0: ++n→1 (print), n=1: ++n→2 (print), n=2: ++n→3 (print), n=3: exit
Output: Iteration: 1
Output: Iteration: 2
Output: Iteration: 3
Pre-increment in loops ensures counter is updated before use. Iterations: 1→2→3
