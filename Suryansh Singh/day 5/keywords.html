What are Keywords ?

Keywords are reserved words in JavaScript that have special meaning and predefined purposes. They are part of the JavaScript language syntax and cannot be used as variable names, function names or identifiers. When the JavaScript interpreter encounters a keyword, it treats it as a language construct rather than a user-defined name.

Examples of keywords include: var, let, const, function, if, else, for, while, return, true, false, null, undefined, class, new, this, typeof and many more. Each keyword has a specific role in the language. For instance, if is used for conditional logic, for is used for loops and function is used to declare functions.

Why Can't Keywords Be Used as Variable Names ?

Reserved for Language Functionality: Keywords are reserved by JavaScript for its core functionality. If you could use them as variable names, it would create ambiguity. For example, if you could create a variable named if, the interpreter wouldn't know whether you're referring to the keyword or your variable.

Syntax Errors: Attempting to use a keyword as a variable name results in a syntax error and your code will not execute. The JavaScript interpreter recognizes keywords immediately and won't allow them to be reassigned or used as identifiers.

Maintaining Code Clarity: By restricting keyword usage, the language maintains clarity and consistency. You can always trust that a keyword will perform its intended function and you must use different names for your variables, which encourages better naming practices.

Invalid: let if = 5; (Syntax Error)
Valid: let condition = 5; (Correct)

Important Keywords and Examples

VAR - Variable Declaration (Old Method)
Definition:

var is the original keyword for declaring variables in JavaScript. It has function scope and can be redeclared and updated. However, var is considered outdated and modern JavaScript prefers let and const.

Syntax:
var variableName = value;
Example 1: Basic Variable Declaration
var name = "Suryansh";
var age = 19;
console.log(name);
console.log(age);
Output: Suryansh
Output: 19
Here, we declare two variables using var. The first variable stores a string and the second stores a number. Variables declared with var can be updated later in the program.
Example 2: Redeclaring Variables
var count = 10;
console.log(count); // 10
var count = 20; // Can redeclare
console.log(count); // 20
Output: 10
Output: 20
Unlike let and const, variables declared with var can be redeclared. However, this can lead to bugs and is not recommended in modern JavaScript.
LET - Block-Scoped Variable Declaration
Definition:

let declares variables with block scope, meaning they only exist within the block (inside curly braces) where they're declared. Variables declared with let can be updated but not redeclared. This is the modern way to declare variables.

Syntax:
let variableName = value;
Example 1: Basic let Declaration
let city = "Lucknow";
let population = 4266929;
console.log(city);
console.log(population);
Output: Lucknow
Output: 4266929
Here, we declare two variables using let. The let keyword is preferred because it prevents accidental redeclaration and provides better scoping.
Example 2: Block Scope with let
let x = 100;
{
let x = 50; // Different x inside the block
console.log(x); // 50
}
console.log(x); // 100 (original x)
Output: 50
Output: 100
Variables declared with let have block scope. The x inside the block is different from the x outside. This prevents naming conflicts and makes code safer.
CONST - Constant (Block-Scoped, Immutable)
Definition:

const declares constants that cannot be changed after initialization. Like let, they have block scope and cannot be redeclared. Use const by default for values that shouldn't change.

Syntax:
const constantName = value;
Example 1: Basic const Declaration
const PI = 3.14159;
const COUNTRY = "India";
console.log(PI);
console.log(COUNTRY);
Output: 3.14159
Output: India
Constants are declared using const. By convention, constant names are written in uppercase. Once declared, these values cannot be changed.
Example 2: Error When Reassigning Constant
const MAX_SCORE = 100;
console.log(MAX_SCORE); // 100
MAX_SCORE = 150; // Error: Assignment to constant variable
Output: 100
Error: TypeError: Assignment to constant variable
Attempting to reassign a constant results in an error. This is by design - const ensures that values remain fixed throughout the program, preventing accidental modifications.
IF - Conditional Statement
Definition:

The if keyword executes a block of code only if a specified condition is true. It's fundamental to controlling program flow based on conditions.

Syntax:
if (condition) {
// code to execute if condition is true
}
Example 1: Simple if Statement
let age = 18;
if (age >= 18) {
console.log("You are an adult");
}
Output: You are an adult
The condition age >= 18 is evaluated. Since age is 18, the condition is true and the code inside the braces executes, printing "You are an adult".
Example 2: if with Comparison
let score = 75;
if (score > 70) {
console.log("Good performance!");
}
Output: Good performance!
The if statement checks if the score is greater than 70. Since 75 > 70 is true, the console.log statement executes.
ELSE - Alternative Condition
Definition:

The else keyword specifies a block of code to execute if the condition in an if statement is false. It provides an alternative path of execution.

Syntax:
if (condition) {
// code if true
} else {
// code if false
}
Example 1: if-else Statement
let number = 5;
if (number % 2 === 0) {
console.log("Even number");
} else {
console.log("Odd number");
}
Output: Odd number
The condition checks if the number is even (divisible by 2). Since 5 is odd, the condition is false and the else block executes, printing "Odd number".
Example 2: if-else with Strings
let username = "admin";
if (username === "admin") {
console.log("Welcome, Administrator!");
} else {
console.log("Welcome, User!");
}
Output: Welcome, Administrator!
The condition checks if the username equals "admin". Since it does, the if block executes. The else would execute if the username were different.
FOR - Loop Statement
Definition:

The for keyword creates a loop that repeats a block of code a specific number of times. It's useful when you know how many times you need to repeat an action.

Syntax:
for (initialization; condition; increment) {
// code to repeat
}
Example 1: Basic for Loop
for (let i = 1; i <= 5; i++) {
console.log(i);
}
Output: 1, 2, 3, 4, 5
The for loop initializes i to 1, continues while i ≤ 5, and increments i by 1 each iteration. This prints numbers 1 through 5.
Example 2: Looping Through Array
let colors = ["red", "green", "blue"];
for (let i = 0; i < colors.length; i++) {
console.log(colors[i]);
}
Output: red
Output: green
Output: blue
The for loop iterates through each element of the array. The condition i < colors.length ensures we don't go beyond the array bounds.
forEach() - Array Iteration Method
Definition:

forEach is an array method (not technically a keyword but a built-in function) that executes a function for each element in an array. It's a modern alternative to traditional for loops.

Syntax:
array.forEach(function(element, index) {
// code to execute for each element
});
Example 1: forEach with Simple Function
let fruits = ["apple", "banana", "mango"];
fruits.forEach(function(fruit) {
console.log(fruit);
});
Output: apple
Output: banana
Output: mango
forEach automatically calls the function for each element. The parameter fruit holds the current element value. No manual loop management is needed.
Example 2: forEach with Index
let numbers = [10, 20, 30];
numbers.forEach(function(num, index) {
console.log("Index " + index + ": " + num);
});
Output: Index 0: 10
Output: Index 1: 20
Output: Index 2: 30
forEach provides both the element and its index. The index parameter gives the position of the element in the array, making it easy to track both value and position.
