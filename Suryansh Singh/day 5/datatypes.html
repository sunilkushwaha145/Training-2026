What are Variables?

A variable is a named container that stores a value in memory. Think of it as a labeled box that holds data. Variables allow you to store, retrieve and manipulate data throughout your program. Each variable has a name (identifier) that you use to reference the value it contains. Variables make code flexible and reusable because you can store different values at different times.

In JavaScript, you declare variables using var, let or const. After declaration, you can assign values to them. Variables can hold different types of data - numbers, strings, booleans, objects and more. This flexibility is one of JavaScript's defining features.

What are Data Types?

A data type specifies what kind of data a variable can hold. JavaScript is dynamically typed, meaning a variable can hold any data type and can change types during execution. The main primitive data types are:

  • String: Text data enclosed in quotes (single or double)
  • Number: Integer or floating-point numeric values
  • Boolean: True or false values
  • Undefined: A variable declared but not assigned a value
  • Null: An explicit absence of value
  • Object: Complex data structures storing collections of data
  • Array: Ordered lists of values

STRING Data Type

A string is text data enclosed in single quotes ('), double quotes ("), or backticks (`). Strings can contain letters, numbers, spaces and special characters. They're used for storing and manipulating text information in your programs.

String Example 1
let name = "Suryansh";
let city = 'Lucknow';
let greeting = `Hello, ${name}`;
console.log(name); // Output in console
console.log(city);
console.log(greeting);
Output: Suryansh
Output: Lucknow
Output: Hello, Suryansh
Here we create three string variables using different quote styles. Double quotes, single quotes and backticks all create strings. Backticks allow template literals with ${} for inserting values.
String Example 2
var email = "suryanshsinghchauhanthakur@gmail.com";
const message = "Welcome to JavaScript!";
document.write("Email: " + email + "");
document.write("Message: " + message + "");
console.log(email);
console.log(message);
Browser displays: Email: suryanshsinghchauhanthakur@gmail.com
Browser displays: Message: Welcome to JavaScript!
Console: suryanshsinghchauhanthakur@gmail.com
Console: Welcome to JavaScript!
Using document.write() displays content directly on the page, while console.log() displays in the browser console. Here we store email and message as strings and display them both ways.

NUMBER Data Type

A number represents numeric values - both integers and decimal numbers. JavaScript treats all numbers as the same type, whether they're whole numbers or have decimal points. Numbers are used for calculations, comparisons and arithmetic operations.

Number Example 1
let age = 19
let height = 5.7;
let score = 95.5;
console.log(age); // Integer
console.log(height); // Float
console.log(score);
Output: 19
Output: 5.7
Output: 95.5
Numbers can be integers (whole numbers) or floats (decimals). JavaScript automatically handles both types. The console displays them as typed.
Number Example 2
const price = 299.99;
var quantity = 5;
let total = price * quantity;
document.write("Price: " + price + "");
document.write("Quantity: " + quantity + "");
document.write("Total: " + total + "");
console.log("Calculation: " + price + " * " + quantity + " = " + total);
Browser displays: Price: 299.99
Browser displays: Quantity: 5
Browser displays: Total: 1499.95
Console: Calculation: 299.99 * 5 = 1499.95
Numbers can be used in arithmetic operations. Here we calculate the total by multiplying price and quantity. We display results both on the page and in the console.

BOOLEAN Data Type

A boolean is a data type that can only have two values: true or false. Booleans are used for logical operations and control flow decisions. They're essential for conditional statements and loops.

Boolean Example 1
let isStudent = true;
let hasDriverLicense = false;
let isLoggedIn = true;
console.log(isStudent);
console.log(hasDriverLicense);
console.log(isLoggedIn);
Output: true
Output: false
Output: true
Boolean variables explicitly store true or false values. These are commonly used to track states like whether a user is logged in, if a feature is enabled or other binary conditions.
Boolean Example 2
const age = 20;
const minAge = 18;
let canVote = age >= minAge;
document.write("Age: " + age + "");
document.write("Can Vote: " + canVote + "");
console.log("Age >= 18: " + canVote);
Browser displays: Age: 20
Browser displays: Can Vote: true
Console: Age >= 18: true
Boolean values result from comparison operations. When we check age >= minAge, it returns true or false based on the comparison. This is how conditionals make decisions.

Using document.write() and console.log()

document.write(): Writes content directly to the HTML page. Use it to display information that should appear in the browser window. HTML formatting is supported.

console.log(): Outputs content to the browser's JavaScript console (F12 or Ctrl+Shift+J). Use it for debugging and testing. Console messages don't appear on the page.
