What are Functions ?

A function is a reusable block of code that performs a specific task. Functions allow you to write code once and use it multiple times. They help organize code, reduce duplication and make programs easier to understand and maintain. Functions can accept parameters (input) and return values (output), making them flexible and powerful tools in programming.

There are two types of functions in JavaScript: User-Defined Functions (created by programmers) and Built-in Functions (provided by JavaScript itself). Understanding both is essential for effective programming.

User-Defined Functions

User-defined functions are functions you create to perform specific tasks in your application. They follow this syntax:

function functionName(parameters) {
// code to execute
return result; // optional
}
Example 1: Simple Function
function greet() {
console.log("Hello, Welcome!");
}
greet(); // Call the function
Output: Hello, Welcome!
This function has no parameters and no return value. It simply displays a message when called. Functions are called using their name followed by parentheses: greet()
Example 2: Function with Parameters
function add(a, b) {
return a + b;
}
let result = add(5, 3);
console.log("Sum: " + result);
Output: Sum: 8
This function accepts two parameters (a, b) and returns their sum. We pass arguments 5 and 3 when calling the function and it returns 8. The return keyword sends the result back to the caller.
Example 3: Function with Multiple Operations
function calculateArea(length, width) {
let area = length * width;
return area;
}
let room = calculateArea(10, 5);
console.log("Room area: " + room + " sq units");
Output: Room area: 50 sq units
Functions can perform multiple operations. Here we calculate the area by multiplying length and width then return the result.
Example 4: Function Checking Conditions
function isEven(num) {
if (num % 2 === 0) {
return true;
} else {
return false;
}
}

console.log(isEven(4)); // true
console.log(isEven(7)); // false
Output: true
Output: false
Functions can include conditional logic. This function checks if a number is even by testing if it's divisible by 2, returning true or false accordingly.
Example 5: Function with String Operations
function fullName(first, last) {
return first + " " + last;
}

let name = fullName("Suryansh", "Singh");
console.log("Full Name: " + name);
Output: Full Name: Suryansh Singh
Functions work with different data types. Here we concatenate two string parameters to create a full name. Strings can be combined using the + operator.
Example 6: Function Calculating Grade
function getGrade(marks) {
if (marks >= 90) return "A";
else if (marks >= 80) return "B";
else if (marks >= 70) return "C";
else return "F";
}

console.log("Grade: " + getGrade(85));
console.log("Grade: " + getGrade(72));
Output: Grade: B
Output: Grade: C
Ladder if statements inside functions determine which grade to return based on marks. This demonstrates complex decision-making within functions.
Example 7: Function with Default Values
function multiply(a, b = 1) {
return a * b;
}

console.log(multiply(5, 3)); // 15
console.log(multiply(5)); // 5 (b defaults to 1)
Output: 15
Output: 5
Functions can have default parameter values. If b is not provided, it defaults to 1. This makes functions more flexible.
Example 8: Function Displaying on Page
function displayMessage(message) {
document.write(message + "");
console.log("Displayed: " + message);
}

displayMessage("Welcome to JavaScript!");
displayMessage("Functions are powerful!");
Browser shows: Welcome to JavaScript!
Browser shows: Functions are powerful!
Console logs both messages
Functions can perform different types of operations including displaying content on the page with document.write() and logging to console.
Example 9: Function with Array
function sumArray(arr) {
let sum = 0;
for (let i = 0; i < arr.length; i++) {
sum = sum + arr[i];
}
return sum;
}

let numbers = [10, 20, 30, 40];
console.log("Total: " + sumArray(numbers));
Output: Total: 100
Functions can accept complex data types like arrays. Here we loop through the array to calculate the sum of all elements.
Example 10: Function Calling Another Function
function square(x) {
return x * x;
}

function calculateArea(side) {
return square(side);
}

console.log("Area of square with side 5: " + calculateArea(5));
Output: Area of square with side 5: 25
Functions can call other functions. Here calculateArea calls square to compute the area. This modular approach makes code more organized.

Built-in Functions

Built-in functions are functions provided by JavaScript itself. They're already available and ready to use without requiring you to write them. Common built-in functions include alert(), confirm(), prompt(), console.log(), parseInt() and many others.

alert() - Display Alert Dialog

Purpose: Displays a popup dialog with a message and an OK button. The script pauses until the user clicks OK. Alert is useful for displaying important messages to users.

Syntax: alert(message);

Output: Displays a modal popup dialog box

alert() Example 1
alert("Welcome to this page!");
This displays a simple popup message. When you run this, an alert box appears with the message "Welcome to this page!" and an OK button.
alert() Example 2
let name = "Suryansh";
alert("Hello, " + name + "!");
Alert can display dynamic content. Here we concatenate a variable with text to create a personalized message. The alert shows: "Hello, Suryansh!"
alert() Example 3
let score = 95;
alert("Your score is: " + score + " out of 100");
Alert can display information about calculations or data. This example shows a score with context. Very useful for notifications and confirmations.
alert() Example 4
alert("Error: File not found!\nPlease try again.");
The \n adds a line break in the alert message. This helps format multi-line messages clearly. Error messages often use this format.
alert() Example 5
let product = "Laptop"; let price = 39999.99; alert(product + " costs Rs" + price + ". Interested?");
Complex messages combining multiple variables work well with alert. This showcases a product with price information.
confirm() - Confirmation Dialog

Purpose: Displays a dialog with a message and two buttons: OK and Cancel. Returns true if the user clicks OK, false if they click Cancel. Useful for confirming important actions.

Syntax: let result = confirm(message);

Output: Returns boolean value (true/false)

confirm() Example 1
let userChoice = confirm("Do you want to continue?");
console.log("User said: " + userChoice);
Confirm returns true if OK is clicked, false if Cancel is clicked. The result is stored and can be used for conditional logic.
confirm() Example 2
if (confirm("Are you sure you want to delete?")) {
console.log("Deleting...");
alert("Item deleted!");
} else {
console.log("Deletion cancelled");
alert("Deletion cancelled");
}
Confirm is perfect for confirmation dialogs before performing important actions. The if-else structure handles different user responses.
confirm() Example 3
let isAdmin = confirm("Admin login?");
if (isAdmin) {
alert("Welcome, Administrator!");
} else {
alert("Welcome, User!");
}
Confirm can be used for branching logic based on user choice. Different messages display based on whether the user confirms or cancels.
confirm() Example 4
let proceed = confirm("Submit form with the following data?\n\nName: Suryansh\nEmail: suryanshsinghchauhanthakur@gmail.com");
if (proceed) {
document.write("Form submitted successfully!");
} else {
document.write("Form submission cancelled");
}
Multi-line messages help users understand what they're confirming. This example shows form submission confirmation with user data preview.
confirm() Example 5
let quantity = 5;
let price = 50;
let total = quantity * price;
let buyConfirm = confirm("Buy " + quantity + " items for Rs" + total + "?");
console.log("Purchase confirmed: " + buyConfirm);
Confirm can display calculated information for user review before confirming an action. Useful for e-commerce and transaction systems.
prompt() - Input Dialog

Purpose: Displays a dialog that prompts the user to enter text. Returns the entered text as a string or null if Cancel is clicked. Useful for collecting user input.

Syntax: let userInput = prompt(message, defaultValue);

Output: Returns string value of user input

prompt() Example 1
let name = prompt("What is your name?");
console.log("User entered: " + name);
alert("Hello, " + name + "!");
Prompt gets user input and stores it in a variable. The entered text can then be used in your program. This is how you collect information from users.
prompt() Example 2
let age = prompt("How old are you?", "18");
console.log("Age: " + age);
if (age >= 18) {
alert("You are an adult");
} else {
alert("You are a minor");
}
Prompt can have a default value (second parameter). "18" appears pre-filled in the input box. The input can then be used in conditional logic.
prompt() Example 3
let email = prompt("Enter your email:");
if (email !== null) {
console.log("Email: " + email);
alert("Thank you! We have your email: " + email);
} else {
console.log("User cancelled");
alert("Email entry cancelled");
}
Checking for null handles cases where the user clicks Cancel. This prevents errors when processing user input. The !== operator checks if the value is not null.
prompt() Example 4
let score = prompt("Enter your score (0-100):");
let scoreNum = parseInt(score);
if (scoreNum > 80) {
alert("Excellent!");
} else if (scoreNum > 60) {
alert("Good");
} else {
alert("Needs improvement");
}
Prompt returns a string, so parseInt() converts it to a number for comparison. This demonstrates type conversion and using input in conditional logic.
prompt() Example 5
let color = prompt("What is your favorite color?", "Blue");
document.write("Your favorite color is: " + color + "");
console.log("Color preference: " + color);
Prompt input can be used to create dynamic content. Here the user's favorite color input is displayed with that color styling. Shows how user input can customize page content.
