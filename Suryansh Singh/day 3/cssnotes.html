CSS Notes

What is CSS?

CSS stands for Cascading Style Sheets. It is a language used to style HTML webpages. CSS controls the colors, fonts, spacing, layouts, and overall appearance of a website. It helps make webpages attractive and user-friendly. CSS separates the design from the content of a webpage. It is one of the most important technologies used in web development.

Why Do We Use CSS?

CSS is used to improve the appearance of websites. It allows developers to apply consistent styles across multiple pages. CSS saves time because styles can be reused. It helps create responsive and modern designs. CSS improves the user experience by making websites easier to read and navigate. Without CSS, webpages would look plain and unorganized.

Difference Between Inline, Internal and External CSS

Inline CSS is written directly inside an HTML tag using the style attribute. It affects only one specific element. Internal CSS is written inside the style tag in the head section of an HTML page. It affects the entire webpage where it is written. External CSS is written in a separate .css file and linked to HTML using the link tag. External CSS is the best method because one CSS file can style many webpages at the same time.
