## 📘 About This Repository

This repository is the **central hub** for the **FullStack Development Training Program — Batch 2026**, under the mentorship of **Sunil Kushwaha**. It hosts all course assignments, practice projects and hands-on exercises completed by enrolled students throughout the training lifecycle.

Each student maintains their own dedicated folder containing progressive work covering:

- 🌐 **Front-End**: HTML5, CSS3, JavaScript, Bootstrap
- ⚙️ **Back-End**: C#, ASP.NET Core MVC / Web API
- 🗄️ **Database**: SQL Server, Entity Framework Core, LINQ
- 🔗 **Integration**: RESTful APIs, JSON, AJAX
- 🚀 **DevOps Basics**: Git, GitHub, deployment fundamentals

## 📋 Assignment Submission Guidelines

> Students must follow these guidelines for every assignment submission:

1. **Fork or clone** this repository to your local machine.
2. Navigate to **your personal folder** inside the repo.
3. Create a new sub-folder for each assignment/project using the format:
   ```
   Assignment-<Number>-<Topic>/
   ```
4. Add all source files, screenshots and a short `README.md` explaining the task.
5. **Commit with meaningful messages**:
   ```bash
   git add .
   git commit -m "Added Assignment-07"
   git push origin main
   ```
6. Keep your code **clean, commented and well-structured**.

## ⚙️ Getting Started

### Prerequisites

Make sure the following are installed on your system:

```
✅ Visual Studio 2022 (Community or above)
✅ .NET 8 SDK
✅ SQL Server 2019/2022 + SSMS
✅ Git
✅ Node.js (for front-end tooling)
```

### Clone the Repository

```bash
git clone https://github.com/sunilkushwaha145/Training-2026.git
cd Training-2026
```

### Running a .NET Core Project

```bash
cd "Your_folder/Your_Project"
dotnet restore
dotnet run
```
